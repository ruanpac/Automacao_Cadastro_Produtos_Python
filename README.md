# 🤖 Automação de Cadastro de Produtos

Automação em **Python** que lê produtos de uma planilha Excel e realiza o cadastro automaticamente em um sistema web utilizando **PyAutoGUI**.

## 🛠️ Tecnologias

* Python
* Pandas
* PyAutoGUI
* Pyperclip
* OpenPyXL



## 🎥 Demonstração

[▶️ Clique aqui para assistir ao vídeo da automação rodando no meu PC](https://youtu.be/xkW28ryMXL8)



## ⚙️ Como executar

**É necessário ter Python instalado no computador e instalar todas as bibliotecas utilizadas no projeto.**

Instale as dependências com:

```bash
pip install pyautogui pandas pyperclip openpyxl
```

Depois, execute:

```bash
python AutomacaoPyautogui.py
```

A planilha `20produtos.xlsx` deve estar na mesma pasta do código.

## 📌 Observação

A automação utiliza teclado, mouse e posições da tela. Alterações na resolução ou no layout do sistema podem exigir ajustes no código.

Projeto desenvolvido para **estudo e portfólio**, com foco em Python e RPA.
